# MEN'S — Figma to HTML/CSS Portfolio Project

A responsive men's fashion landing page recreated from the supplied Figma design.

## Files

- `index.html` — semantic page structure
- `css/style.css` — layout, typography, responsive design
- `js/script.js` — mobile menu, wishlist and simple cart interactions

## How to run

1. Open the folder in VS Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Replace the demo Unsplash image URLs with your exported Figma images for a 1:1 visual match.

## Recommended portfolio description

"Responsive men's fashion e-commerce landing page designed in Figma and developed with semantic HTML, modern CSS, responsive layouts and lightweight JavaScript interactions."

## Important

The image URLs are demonstration assets. For a professional portfolio submission, export the original image assets from Figma and put them in `images/`, then replace each `<img src="...">` URL with a local path such as `images/hero.jpg`.
